# Прогнозирование цен бриллиантов с AutoML и SHAP

Проект выполняет полный цикл анализа данных: от разведочного анализа до построения модели машинного обучения и генерации аналитического отчёта. Модель предсказывает цену бриллианта в долларах США по его характеристикам: вес, размеры, качество огранки, цвет и чистота.

## Как использовать

Модель принимает на вход характеристики бриллианта и возвращает прогнозируемую цену:

```python
# Пример: бриллиант 1.5 карата, огранка Ideal, цвет G, чистота VS1
predictor.predict(pd.DataFrame({
    'carat': [1.5],
    'cut': ['Ideal'],
    'color': ['G'],
    'clarity': ['VS1'],
    'depth': [61.5],
    'table': [57.0],
    'x': [7.3],
    'y': [7.4],
    'z': [4.5]
}))
```
